# DateBot

Userbot на .NET 10: от имени владельца отвечает на лайки в сервисах знакомств, а обо всём важном пишет ему через бота-уведомителя. Первая площадка — Tashdate (чат бота и его Telegram Mini App), следующая — Badoo.

## Куда смотреть

- **C#** — перед тем как писать или ревьюить код, прочитай [CODING_STANDARDS.md](CODING_STANDARDS.md): слои, папки по видам, ошибки через `Result`, value objects, команды, адаптеры, хранение и миграции, тесты.
- **Поведение и настройки** — [README.md](README.md): как работает сервис, секции `appsettings.json`, кнопки бота-уведомителя и «Решения, принятые при реализации» с причинами.

- **Новый формат сообщения бота** — [docs/samples/README.md](docs/samples/README.md): как подготовить образец и где добавить тест разбора.

## Команды

```bash
dotnet tool restore
dotnet build DateBot.slnx
dotnet test DateBot.slnx
dotnet format DateBot.slnx --severity warn
dotnet format DateBot.slnx --verify-no-changes --severity warn
```

`dotnet format` без `--verify-no-changes` сам чинит пробелы, концы строк и `using`. `dotnet tool restore` ставит `dotnet ef` для миграций.

## Готово = зелёное

Работа закончена, когда зелёное всё:

1. `dotnet build` проходит. Предупреждения, неиспользуемые `using` и битые `cref` ломают сборку.
2. `dotnet test` проходит, и у каждого нового или изменённого поведения есть тест.
3. `dotnet format --verify-no-changes` молчит.
4. Менялась модель EF — есть миграция, и `has-pending-model-changes` сообщает, что изменений нет.
5. Поменялось то, что видит владелец (поведение, настройка, кнопка, текст уведомления), — README и `appsettings.json` описывают новое.

Коммит делается отдельной командой после зелёного прогона.

## Ограждения

- **Живые аккаунты — только чтение.** В настоящем Telegram, в чате бота Tashdate и в Mini App можно читать. Лайк, сообщение или нажатие кнопки там делаются только по прямой просьбе владельца: это его аккаунт и его знакомства.
- **Секреты вне репозитория.** `api_id`, `api_hash`, телефон, токены и ключи живут в user-secrets или переменных окружения. Сессия, база и фото лежат в `%LOCALAPPDATA%\DateBot`.
- **Язык выбирает читатель.** Код, комментарии, логи и коммиты — по-английски, тема коммита в повелительном наклонении. Всё, что читает владелец (тексты уведомлений, `Error.Message`, сообщения проверки настроек), README и `docs/` — по-русски.
